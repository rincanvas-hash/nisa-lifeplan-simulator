# 50代からの未来設計シミュレーター

Python と Streamlit で作成した、日本語の未来設計シミュレーターです。現在の金融資産、退職前の積立、想定利回り、退職後の生活費と年金収入から、将来の資産残高の目安を確認できます。

## 画面構成

1. **はじめに** — 案内キャラクターがシミュレーターを紹介
2. **条件入力** — 万円単位の入力と円換算を確認
3. **結果** — 4つの結果、資産推移グラフ、年間結果表を表示

入力値は Streamlit のセッション状態に保持されるため、ページを戻っても入力し直す必要はありません。各画面のキャラクターと吹き出し、立体感のある CTA、スマートフォン向けのレスポンシブ表示も備えています。

## 計算の前提

- 退職前は、現在の資産に毎月の積立額と想定利回りを反映します。
- 退職後は、毎月の生活費から年金収入を差し引いた不足額を資産から取り崩します。
- 資産が残っている間は、退職後も同じ想定利回りを反映します。
- 資産残高は 0 円未満として表示しません。
- 税金、社会保険料、物価上昇、退職金、夫婦での計算は含めていません。

このツールは教育目的の概算であり、金融助言や将来の成果を保証するものではありません。

## セットアップと起動

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

## テスト

```bash
pytest
```

テストは `tests/` フォルダにあります。
